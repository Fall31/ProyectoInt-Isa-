DESDE POSTMAN O CURL:

1. Subir imagen:
   POST http://localhost:5000/api/imagen/cliente/subir
   - Body: form-data
   - imagen: [seleccionar archivo]
   - ci_cliente: 12345678

2. Eliminar imagen:
   DELETE http://localhost:5000/api/imagen/cliente/eliminar
   - Body: JSON
   {
     "ci_cliente": "12345678",
     "urlPublica": "https://..."
   }
