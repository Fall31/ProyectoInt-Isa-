PASO 1️⃣: EJECUTAR SQL EN SUPABASE
───────────────────────────────────────────────────────────────────────────────

Archivo: SQL_AGREGAR_COLUMNAS.sql

Acciones:
   1. Ve a Supabase Dashboard → SQL Editor
   2. Copia el contenido de SQL_AGREGAR_COLUMNAS.sql
   3. Pega en el editor y haz click en RUN
   
Resultado esperado:
   ✅ Columna foto_url agregada a: cliente, servicio, catalogoproducto, vacuna

PASO 2️⃣: CREAR BUCKETS EN STORAGE
───────────────────────────────────────────────────────────────────────────────

Buckets a crear (todos como "Public"):
   1. imagenes_clientes
   2. imagenes_mascotas
   3. imagenes_productos
   4. imagenes_servicios
   5. imagenes_doctores

Acciones:
   1. Ve a Supabase Dashboard → Storage
   2. Click "Create bucket"
   3. Ingresa el nombre (ej: imagenes_clientes)
   4. Marca como "Public"
   5. Click "Create bucket"
   6. Repite para los 5 buckets

PASO 3️⃣: CONFIGURAR POLÍTICAS RLS (OPCIONAL PERO RECOMENDADO)
───────────────────────────────────────────────────────────────────────────────

Archivo: POLITICAS_RLS_STORAGE.sql

Para cada bucket:
   1. Ve a Storage → [nombre_bucket] → Policies
   2. Click "New Policy"
   3. Copia cada SELECT, INSERT, UPDATE, DELETE de POLITICAS_RLS_STORAGE.sql
   4. Pega y aplica

PASO 4️⃣: ACTUALIZAR CONTROLLERS FRONTEND
───────────────────────────────────────────────────────────────────────────────

Crear endpoints para subir imágenes:

   POST /api/cliente/subir-imagen
   POST /api/mascota/subir-imagen
   POST /api/producto/subir-imagen
   POST /api/servicio/subir-imagen
   POST /api/doctor/subir-imagen

Usar ImagenService para manejar la lógica
